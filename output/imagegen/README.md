# Seoul header style concepts

These concepts compare three visual directions for the `ap-northeast-2` AWS Console header.

## Shared scene

- N Seoul Tower as the central landmark
- Bukhansan mountain ridge
- A subtle Han River and city skyline
- Blue-hour palette: charcoal navy, muted indigo, cyan, and restrained coral
- No text, logos, interface elements, people, flags, or watermark

## Variants

1. `seoul-atmospheric-panorama.png`
   - Premium atmospheric panoramic illustration
2. `seoul-3d-diorama.png`
   - Polished miniature 3D diorama
3. `seoul-minimal-lineart.png`
   - Minimal cyan monoline illustration

Each source image is `1536 x 1024`. The matching `*-header.png` file is a `1536 x 256` visual preview cropped for side-by-side evaluation. Production dimensions will be finalized after inspecting the live AWS Console header.
